# Дизайн-система «Цифровая очередь» — Почта России

## Обзор

Светлая, чистая и профессиональная дизайн-система, основанная на фирменном стиле Почты России. Дизайн избегает типичных признаков AI-генерации (избыточные градиенты, тени, слишком круглые углы) в пользу четких линий, ясной типографики и функциональности.

## Философия дизайна

### Принципы
- **Ясность превыше всего**: четкая визуальная иерархия, легкая читаемость
- **Профессионализм**: сдержанный, официальный стиль государственной организации
- **Доступность**: соответствие WCAG 2.1 AA, режим для слабовидящих
- **Функциональность**: каждый элемент имеет четкую цель

### Что мы избегаем (AI-слоп)
- ❌ Множественные градиенты
- ❌ Избыточные тени и blur-эффекты
- ❌ Слишком круглые углы (>12px без причины)
- ❌ Неоновые цвета и saturated палитры
- ❌ Анимации без цели
- ❌ Сложные background-паттерны

## Типографика

### Шрифты

```css
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
```

Системные шрифты обеспечивают:
- Быструю загрузку (0 байт)
- Нативный вид на каждой платформе
- Отличную читаемость

### Размеры шрифтов

| Назначение | Размер | Использование |
|------------|--------|---------------|
| Заголовок H1 | 1.5-1.625rem | Главные заголовки страниц |
| Заголовок H2 | 1.125-1.25rem | Заголовки секций |
| Заголовок H3 | 1-1.125rem | Подзаголовки |
| Основной текст | 0.875-1rem | Тело текста |
| Мелкий текст | 0.75-0.8125rem | Подписи, метаданные |
| Большие цифры | 2-3.5rem | Номера талонов, KPI |

### Начертание

- **Regular (400)**: основной текст
- **Medium (500)**: метки форм, навигация
- **Semi-Bold (600)**: заголовки, кнопки
- **Bold (700)**: цифры, акценты

## Компоненты

### Радиусы скругления

```css
--radius: 6px      /* Стандартный */
--radius-lg: 8px   /* Большой для карточек */
```

Умеренные радиусы создают современный, но не игрушечный вид.

### Отступы

```css
--space: 1rem     /* Базовый отступ (16px) */
```

Используем кратные значения: 0.25rem, 0.5rem, 0.75rem, 1rem, 1.25rem, 1.5rem, 2rem.

### Кнопки

#### Варианты

**Primary** (основная)
```css
background: #003B73
color: #FFFFFF
padding: 0.75rem 1.25rem
border-radius: 6px
```

**Secondary** (второстепенная)
```css
background: #FFFFFF
color: #003B73
border: 1px solid #D0D7E2
```

**Danger** (опасное действие)
```css
background: #FFFFFF
color: #D32F2F
border: 1px solid #D32F2F
```

### Карточки

```css
background: #FFFFFF
border: 1px solid #E3E8EF
border-radius: 8px
padding: 1.25rem
```

Простые карточки с тонкой границей без теней (или минимальная тень для поднятия).

### Поля ввода

```css
padding: 0.625rem 0.875rem
border: 1px solid #D0D7E2
border-radius: 6px
background: #FFFFFF
```

**Focus состояние:**
```css
border-color: #0055A5
box-shadow: 0 0 0 3px rgba(0, 85, 165, 0.1)
```

### Бейджи (Badge)

```css
display: inline-flex
padding: 0.25rem 0.625rem
border-radius: 9999px  /* Полностью круглый */
font-size: 0.75rem
font-weight: 600
text-transform: uppercase
letter-spacing: 0.025em
```

## Состояния интерфейса

### Hover (наведение)

- Легкое изменение цвета фона/границы
- transition: 150ms ease
- Без излишних эффектов

### Focus (фокус)

- Видимый outline или box-shadow
- Цвет акцента (#0055A5)
- 3px ring для доступности

### Disabled (отключено)

```css
opacity: 0.5
cursor: not-allowed
```

### Loading (загрузка)

Простой spinner:
```css
border: 2px solid rgba(255, 255, 255, 0.3)
border-top-color: #FFFFFF
animation: spin 0.8s linear infinite
```

## Адаптивность

### Breakpoints

```css
mobile: < 480px
tablet: 481px - 768px
desktop: 769px - 1024px
wide: > 1024px
```

### Принципы

- Mobile-first подход
- Гибкие сетки (flexbox, grid)
- Масштабируемые отступы
- Условная типографика (clamp, media queries)

## Доступность

### Режим для слабовидящих

Система поддерживает специальный режим:

```css
html.a11y-mode {
  font-size: 115%;
}

html.a11y-mode.a11y-contrast {
  --background: #000000;
  --surface: #000000;
  --text: #ffffff;
  --brand-primary: #ffff00;  /* Желтый */
  --brand-accent: #00ffff;   /* Cyan */
}
```

Активация через UI переключатель.

- ✅ Интерактивные элементы не менее 44×44px
- ✅ Клавиатурная навигация
- ✅ ARIA-метки где нужно
- ✅ Focus indicators

## Использование

### Импорт

```tsx
// main.tsx
import './design-system.css';
```

Дизайн-система автоматически применяется ко всему приложению.

### CSS переменные

```css
.my-component {
  background: var(--surface);
  color: var(--text);
  border: 1px solid var(--border);
  border-radius: var(--radius);
  padding: var(--space);
}
```

### Классы

Используйте семантические классы из соответствующих CSS-модулей:

```tsx
// Клиент
<div className="cx-home-card">...</div>

// Оператор
<div className="operator-card">...</div>

// Админ
<div className="admin-panel-card">...</div>
```
